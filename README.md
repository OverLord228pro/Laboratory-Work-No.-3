## Объяснение по реализации

Сортировки переставляют узлы двусвязного списка через изменение связей. Доступ к узлу по индексу требует обхода списка. В рассматривавшейся функции deque_get_node дополнительно вызывается deque_size, которая также обходит список. Эти обходы повторяются при восстановлении кучи и могут составлять значительную часть времени пирамидальной сортировки.
Стандартная оценка O(n log n) для пирамидальной сортировки массива опирается на постоянную стоимость доступа по индексу. К данной реализации на списке её напрямую применять нельзя. При линейной стоимости deque_get_node получается верхняя оценка O(n² log n) для этапа последовательного извлечения элементов. Для пузырьковой сортировки списка худшая оценка — O(n²), а проход с ранним выходом на уже упорядоченных данных — O(n).
